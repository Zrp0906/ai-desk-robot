# 贾维斯 · 旧手机 AI 桌面机器人

一台能中文对话、拍照找纸巾的桌面机器人原型。Android 旧手机负责录音、拍照和播报，Mac 负责语音转写、对话和图像识别。开启相机后，可以说「帮我找纸巾」，让贾维斯截取当前预览的一帧并播报位置。普通聊天和找物回复都会显示字幕，播报时有口型动画。

## 在 Mac 上启动

使用 Python 3.9 或以上和 Ollama。在终端打开 Ollama，确认已有 `qwen2.5:1.5b`。如果 `ollama list` 中缺少模型，运行 `ollama pull qwen2.5:1.5b`。

```sh
open -a Ollama
ollama list
```

如果模型下载失败，可以下载 Qwen 发布的 `qwen2.5-1.5b-instruct-q4_k_m.gguf`，再按 Ollama 的 GGUF 导入步骤创建本地模型 `qwen2.5:1.5b`。[Qwen 模型文件](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/tree/main) · [Ollama 导入说明](https://docs.ollama.com/import#importing-a-gguf-model)

进入本仓库目录，第一次运行时安装 Python 依赖，随后启动原型。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

在 Chrome 中打开 `http://127.0.0.1:8781`。第一次录音时允许麦克风访问。首次中文转写需要联网下载 Whisper `base` 模型，下载后转写和对话都在 Mac 上完成。浏览器有可用的本机中文语音时直接播报，否则 Mac 用系统中文语音生成音频，再由浏览器播放。字幕和当前对话保存在页面内存中，刷新后清空。

## 在旧 Android 手机上试用

在 Mac 上安装 Android SDK Platform-Tools，将 `adb` 加入 `PATH`。用 USB 数据线连接手机与 Mac，在手机上开启并授权 USB 调试。

```sh
adb devices
adb reverse tcp:8781 tcp:8781
```

`adb devices` 应显示一台状态为 `device` 的手机。保持 USB 连接，在**手机** Chrome 里打开 `http://127.0.0.1:8781`，点击「开始说话」并允许麦克风。若浏览器等待手动播放，点「重播回答」。备用播报默认使用 Mac 的普通话语音 `Tingting`，可用 `JARVIS_TTS_VOICE=语音名称` 指定 Mac 上另一种已安装的语音。

## 拍照找纸巾

确认 `ollama list` 里有视觉模型 `qwen3-vl:2b`。如果缺少该模型，运行 `ollama pull qwen3-vl:2b`。

在手机页面保留目标「纸巾」，点「拍照找物」。首次使用时按提示允许 Chrome 使用相机。拍一张包含桌面的照片并确认使用。网页会把图片等比缩到最长边不超过 1024 像素，提交给 Mac 上的视觉模型。位置会显示在对话字幕里并播报，也可以点「重播回答」。

把纸巾放在画面左侧、中间、右侧各拍一张，再拍一张没有纸巾的照片。依次核对「左侧」「中间」「右侧」「没找到」。

## 语音找纸巾

在手机 Chrome 里点「开启相机」，允许相机权限，让预览中的镜头对准桌面。页面会优先使用后置摄像头。

点「开始说话」，说「帮我找一下纸巾」，然后点「说完了」。语音转写完成后，贾维斯会截取当前预览的一帧，自动缩图、识别并播报位置。也支持「纸巾在哪里」以及在输入框发送同样的指令。相机未开启时，会提示先开启相机。普通聊天继续使用对话模型。

把纸巾从画面左侧移到右侧，再移出画面。每次说「帮我找纸巾」，核对回复是否分别为「左侧」「右侧」「没找到」。使用时保持页面在前台。结束后点「关闭相机」释放摄像头，离开页面也会关闭相机。

## 验收三轮语音对话

1. 说「贾维斯，我叫小周，周末的周」，确认页面出现这句话的字幕，并能播放贾维斯的回复。
2. 说「我养了一只叫芝麻的猫」，观察录音时的聆听状态和播报时的口型。
3. 说「我叫什么，我的猫叫什么」，确认贾维斯根据前两轮回答「小周」和「芝麻」。

页面也可以输入文字，便于单独测试对话模型。需要换成本机已有的对话模型时，用 `JARVIS_CHAT_MODEL=模型名 .venv/bin/python server.py` 启动。

## 下一步接入单轴转台

目前的找物功能使用手机当前视野。下一阶段用带轴承的水平底座固定手机，选一套能由 Mac 通过 USB 串口指定角度的舵机和驱动板，并配套电源。先手动验证左、中、右三个角度和停止指令，再接入「转到预设角度、停稳、拍照识别」的搜索流程。找到纸巾就停下并播报，扫完仍未找到就结束本轮搜索。完整验收标准见[第一版开发目标](第一版开发目标.md)。

## 本地运行数据

在旧手机上试用时，录音和照片经 USB 转发到 Mac 上的本地服务。模型缓存和本地测试素材放在 Git 忽略的 `runtime/` 目录。录音、照片和本机凭据应留在本地。
